# AGENTS.md — Барбершоп-бот BARBERVAULT

## О проекте
Telegram-бот для записи в барбершоп **BARBERVAULT** (Москва, Воронежская ул., 44, корп. 1А).
Кейс 4.2 из курса Zerocoder — пошаговая запись с контактами клиента.
8 шагов, ~45 секунд до записи.

## Стек
- Python 3.12 + aiogram 3.30.0
- FSM (MemoryStorage) — 9 состояний диалога
- InlineKeyboardBuilder — все клавиатуры инлайн
- python-dotenv — токен в `.env`
- CSV-файлы для данных (редактируются в Excel):
  - `services.csv` — прайс-лист (11 услуг)
  - `barbers.csv` — мастера (3 барбера)
  - `bookings.csv` — записи клиентов (сохраняются при каждом бронировании)

## FSM-состояния (8 шагов)
```
choosing_service → choosing_barber → choosing_date → choosing_time
→ entering_name → entering_phone → entering_email → accepting_privacy → confirming
```
Навигация «Назад» доступна на шагах 1–3.

После entering_name и entering_phone сообщения пользователя удаляются (приватность).

## Режим работы
- ПН–СБ: 10:00–21:00 (11 слотов в час)
- ВС: выходной (пропускается в выборе дат)

## Bookings CSV (bookings.csv)
Формат: `id, date, time, service, price, barber, client_name, phone, email, booked_at`
Кодировка: UTF-8 с BOM (открывается в Excel без проблем).
Создаётся автоматически при первой записи.
В `.gitignore` — конфиденциальные данные клиентов.

## Запуск
```bash
cd barbershop-bot
python -m venv venv
venv/Scripts/pip install -r requirements.txt
cp .env.example .env          # BOT_TOKEN=...
venv/Scripts/python bot.py    # запуск
```

## Режимы сообщений (важно!)
- **Стартовый экран**: фото `logo.png` + подпись → нельзя edit_text
- **Шаги записи 1–4**: текстовые сообщения → edit_text работает
- **Шаги 5–7**: message handler'ы (текстовый ввод) → приватные данные удаляются после ввода
- **Переходы с фото на текст**: `delete() + answer()`
